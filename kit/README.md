# FixMyStreet 日本語導入キット（Docker／VPS編）

道路の穴・不法投棄・街路灯の故障などを、住民が地図と写真で通報し、対応機関へ自動で回り、対応状況が公開される——英国 mySociety の通報プラットフォーム **FixMyStreet** を、日本語で・日本の市区町村の境界で動かすためのキットです。当社が公式 Docker イメージで実際に立て、名古屋市の地図上で日本語の通報フォームが動くところまで実測した記録から起こしました。

自治体だけでなく、議員事務所・政党支部が「困りごと受付」として自分の名前で運営することを想定しています（通報先は事務所のメール／担当部署のメールに設定できます）。

## 中身

- `01-構築手順書.md` … 本体。Docker で起動→日本語化→日本の行政境界（MapIt Global）→対応機関と分類の登録→通報の動作確認まで。落とし穴8個
- `AI-START-HERE.md` … Claude Code 等の AI エージェントに渡すと設置を任せられる指示書
- `tools/nagoya-body.sql` … 対応機関（例: 名古屋市）と分類3件を DB に直接登録する SQL。他の市区町村は area id と名前を差し替え
- `tools/find-area.sh` … 緯度経度から MapIt Global の area id（市区町村・区）を引くワンライナー
- `prompts/` … 設置後に AI に頼む作業の指示文（分類の追加・通報先メールの変更・自治体の追加・公開URLの設定）

## 前提

- Docker が動く VPS か自社サーバー（共有レンタルサーバーでは動きません。PHP ではなく Perl＋PostgreSQL＋systemd のコンテナです）
- メモリ 2GB 以上を推奨（コンテナ4つ: nginx / fixmystreet / postgres / memcached）
- 日本語訳は本リポジトリ `locale/ja_JP.UTF-8/` のもの（1,409/1,456 文字列。本家に PR 済み）

## 進め方

人が読んで進めるなら `01-構築手順書.md` を上から。AI に任せるなら `AI-START-HERE.md` を AI に渡してください。
